# CameraM 项目交接文档（2026-04-26）

## 1. 项目概览
- 技术栈：Objective-C + UIKit + AVFoundation。
- 主要入口：`CameraViewController`。
- 核心能力：拍照、相册导入、基础相机控制（闪光灯/分辨率/比例/网格/镜头）、水印渲染与保存。
- 架构现状：`ViewController + ControlsView + BusinessController + Service/Manager` 的渐进重构状态（不是纯 MVVM）。

## 2. 当前目录与职责（高频）
- `CameraM/CameraViewController.m`：页面协调与导航、权限流转、相册与导入流程、面板状态机与方向策略。
- `CameraM/Views/CameraControlsView.m`：拍照页 UI 容器、顶部/底部控制、比例弹层、镜头选择、水印面板挂载。
- `CameraM/Views/WatermarkPanelView.m`：水印快捷面板 + 详情卡片 UI、配置编辑、预览触发。
- `CameraM/Controllers/CameraBusinessController.m`：业务编排、调用拍摄服务、调用渲染器、配置持久化。
- `CameraM/Managers/CMWatermarkRenderer.m`：水印绘制主引擎（模板布局、参数文案、logo/text 组合）。
- `CameraM/Models/CMWatermarkConfiguration.*`：水印配置模型（含新旧字段兼容）。
- `CameraM/Models/CMWatermarkCatalog.m`：水印模板/Logo 编目。
- `CameraM/Common/CMSettingsStorage.m`：NSUserDefaults 持久化。

## 3. 本轮已完成改造（重点）

### 3.1 交互层（拍照页 -> 水印快捷面板 -> 详情卡片）
- 已实现三层交互：
  - 拍照页点击水印入口打开快捷面板。
  - 快捷面板进入详情设置卡片。
  - 详情卡片返回后回到快捷面板。
- 已打通详情可见性回调链：
  - `WatermarkPanelView` -> `CameraControlsView` -> `CameraViewController`。

### 3.2 方向策略
- 设置层可见时（快捷面板/详情卡片）：限制竖屏。
- 设置层关闭后：恢复 `AllButUpsideDown`。
- `CameraViewController` 内有状态驱动方向更新逻辑（含 iOS 16 geometry update）。

### 3.3 水印配置模型扩展
`CMWatermarkConfiguration` 新增：
- `metadataOptions`：多开关参数显示（Lens/Shutter/Aperture/Date/Location）。
- `watermarkAnchor`：锚点布局（含新增 `BottomCenter`）。
- `textFontName`：文本字体名。

兼容策略：
- 旧字段 `preference / preferenceOptions` 与新字段双向兼容映射。
- 解码时包含锚点值范围保护。

### 3.4 水印布局能力
- 锚点支持：`TL / TR / BL / BR / Center / BottomCenter`。
- `Center`：保留“画面中心”。
- `BottomCenter`：新增“底部居中”。

### 3.5 快捷面板样式调整（按参考图）
- 标题改为 `CAPTURE PERSONALIZATION`。
- 快捷区分组命名调整为英文（Frame Style / Logo Selection / Custom Text / Shooting Data / Display Parameters）。
- 相框卡片风格改为紧凑深色样式。
- 面板在拍照页无用户预览图时可隐藏预览区，突出底部配置区。

### 3.6 相框编目调整
`CMWatermarkCatalog` 当前 Frame 顺序：
1. `None`
2. `Hasselblad Minimalist`（`frame.hasselblad.minimalist`）
3. `Bordered`（原 info）
4. `Studio`
5. `Polaroid`

其中 `Hasselblad Minimalist` 已按 Studio-like 渲染规则处理。

## 5. 构建与验证

### 5.1 构建命令
```bash
xcodebuild -project CameraM.xcodeproj -scheme CameraM -sdk iphonesimulator build
```

### 5.2 本地验证结论
- 最近多轮构建均 `BUILD SUCCEEDED`。
- 存在非阻塞 warning（主要是 iOS 新版本 API deprecation），不影响运行。

## 6. 交接后建议优先事项
1. 补 UI 自动化：覆盖 `Quick -> Detail -> Back -> Close`，以及方向锁切换行为。
2. 补模型兼容单测：旧存档到新字段映射、新存档回填旧字段。
3. 梳理渲染器：`CMWatermarkRenderer` 体量较大，建议拆分为布局策略/metadata 解析/绘制执行三层。
4. 统一文案与本地化：当前中英文混排，建议走 `Localizable.strings`。

## 7. 风险与注意事项
- 水印面板当前同时承载“快捷”和“详情”逻辑，若继续扩展功能，复杂度会快速上升。
- 锚点逻辑目前主要针对 inline 模式，模板模式下仍有部分模板内部强布局规则（如 Studio/Polaroid/Info）。
- catalog 与 renderer 通过字符串 ID 约定联动，新增模板需同时修改 catalog + renderer 分支判断。
